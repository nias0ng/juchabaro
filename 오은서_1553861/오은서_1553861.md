# 주간 업무 정리

## 1. 1주차 주간 목표

- AIoT 프로젝트 후보 주제 발굴
- 프로젝트의 필요성, 차별성 및 구현 가능성 검토
- Raspberry Pi, Jetson Orin Nano, 오린카 및 센서 활용 방안 조사
- 제한된 개발 기간 내 구현 가능한 프로젝트 범위 산정

## 2. 진행한 업무

### 2.1 홈트레이닝 자동 기록·분석 서비스 기획

카메라와 거리 센서를 활용해 사용자의 운동을 자동으로 분석하는 홈트레이닝 서비스를 기획했습니다.

검토한 주요 기능은 다음과 같습니다.

- 운동 종류 자동 인식
- 운동 횟수 및 수행 시간 측정
- 관절 좌표 기반 자세 정확도 분석
- 잘못된 자세에 대한 실시간 피드백
- 운동 결과 자동 기록
- 누적 기록 기반 운동 루틴 및 리포트 생성
- 비전 AI와 ToF·초음파 센서의 판단 결과 비교

### 2.2 관련 기술 및 논문 조사

홈트레이닝 서비스 구현을 위해 다음 내용을 조사했습니다.

- 관절 좌표와 각도를 이용한 운동 동작 판별 방식
- 비전 단독 방식과 거리 센서 융합 방식
- Jetson Orin Nano 환경에서의 실시간 추론 가능성
- 운동 기록 기반 리포트 및 루틴 추천 방식
- 관련 홈트레이닝 및 스마트 헬스 시스템 논문

### 2.3 홈트레이닝 주제의 위험 요소 분석

기술 검토와 컨설팅을 통해 다음과 같은 위험 요소를 확인했습니다.

- 자세 추정 기반 홈트레이닝은 이미 유사 프로젝트가 많아 차별화가 어려움
- 홈트레이닝 사용자가 자신의 자세와 기록을 지속적으로 분석하려는 수요가 명확하지 않음
- 카메라 설치 위치와 화각에 따라 인식 정확도가 크게 달라질 수 있음
- 제한된 메모리 환경에서 자세 추정과 운동 분류를 동시에 수행할 경우 성능 저하 가능성이 있음
- 다양한 운동을 지원하려면 많은 영상 데이터와 라벨링 작업이 필요함
- 센서가 AI 판단에 필수적이지 않으면 IoT 장치가 부가 기능으로 보일 수 있음

이를 통해 구현 가능성뿐만 아니라 사용자가 실제로 필요로 하는 문제인지 먼저 검증해야 한다는 점을 확인했습니다.

### 2.4 전자코 기반 서비스 조사

가스 및 냄새 센서를 조합한 전자코 시스템의 구현 가능성을 조사했습니다.

조사한 내용은 다음과 같습니다.

- MEMS 냄새 센서와 MOS 가스 센서의 동작 원리
- 여러 센서의 반응 패턴을 이용한 냄새 분류 방식
- 온도와 습도에 따른 센서값 보정 필요성
- PCA, Random Forest, SVM 등을 이용한 냄새 패턴 분류
- 식용유 산패, 음식물 부패, 악취 및 유해가스 탐지 활용 사례

검토 결과, 단일 센서만으로는 전자코라고 보기 어렵고 여러 센서의 배열과 반복적인 데이터 수집이 필요하다는 점을 확인했다. 또한 센서 안정화, 냄새 시료 관리 및 학습 데이터 확보에 시간이 많이 필요해 현재 프로젝트 일정에서는 위험도가 높다고 판단했습니다.

<br>

## 3. 기술적으로 학습한 내용

- AI 모델의 성능뿐만 아니라 학습 데이터를 확보할 수 있는지가 중요
- 센서는 단순한 부가 장치가 아니라 AI의 오차를 보완하는 역할을 가져야 함
- Jetson에서는 모든 기능을 하나의 무거운 모델로 처리하기보다 경량 모델과 규칙 기반 로직을 조합하는 것이 현실적임
- 프로젝트의 핵심은 많은 기능이 아니라 측정 가능한 문제를 안정적으로 해결하는 것
- 모델 정확도, 측정 오차, 처리 지연시간 등 객관적인 평가 지표가 필요함
- 시연 환경과 실제 사용 환경의 차이를 고려해 초기 단계부터 테스트 환경을 설계해야 함

## 4. 주요 의사결정

- 홈트레이닝 주제는 기술적 구현은 가능하지만 차별성과 사용자 수요가 부족하다고 판단해 재검토하기로 했습니다.
- 전자코 주제는 데이터 수집과 센서 안정화에 대한 위험이 커 우선순위를 낮추기로 했습니다.
- 오린카와 센서가 핵심 문제 해결에 직접 사용되는 시설 점검형 서비스를 중심으로 후보를 좁히기로 했습니다.
- 완전 자율주행보다 지정 경로 주행과 센서 측정 기능을 먼저 구현하는 방향을 고려하기로 했습니다.

## 6. 다음 주 계획

- 최종 후보 2~3개에 대한 기존 서비스 및 논문 조사
- 후보별 사용자와 실제 사용 시나리오 정의
- Jetson Orin Nano에서 객체 탐지 모델 테스트
- 오린카 기본 주행 및 Raspberry Pi와의 통신 확인
- ToF, IMU 등 주요 센서의 측정 오차 테스트
- 후보별 MVP 기능과 추가 기능 분리
- 팀원별 역할과 개발 일정 산정

## 7. 회고

이번 주에는 하나의 아이디어를 빠르게 확정하기보다 여러 주제의 기술적 가능성과 위험 요소를 검증했습니다. 홈트레이닝과 독거노인, 아동 교육 등 다양한 주제를 분석하면서 기술을 사용할 수 있다는 사실만으로는 좋은 서비스가 되지 않으며, 사용자 문제와 기술의 필요성이 자연스럽게 연결되어야 한다는 점을 배웠습니다.

차주에는 아이디어를 추가로 확장하기보다 후보를 좁히고 간단한 기술 실험을 통해 실제 구현 가능성을 확인한 뒤 최종 주제를 결정하여 개발을 시작할 예정입니다.

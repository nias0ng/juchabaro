# 빌드 · 배포 매뉴얼 — 주차바로 (S15P11E202)


## 1. 시스템 구성 개요
- **입주민 앱**: React Native (Expo) — 모바일/웹
- **관리자 웹**: Vue 3 (Vite)
- **백엔드**: Spring Boot 4.1 (Java 21) — REST API
- **DB**: MySQL 8.x
- **리버스 프록시**: Nginx (EC2)
- **엣지(현장)**: Jetson(감시·YOLOv8/ByteTrack), Raspberry Pi(입차·번호판 OCR/PaddleOCR) — EC2와 **Tailscale 사설망**으로 REST 통신
- **CI/CD**: GitLab + Jenkins, **Docker Compose**로 EC2 배포
- **푸시**: Expo Push

## 4. 빌드 방법
### 백엔드
```bash
cd backend
./gradlew clean build        # 산출물: build/libs/*.jar
```
- DB 마이그레이션은 애플리케이션 기동 시 **Flyway가 자동 적용**(V1~V18). `ddl-auto=validate`.

### 입주민 앱 (Expo)
```bash
cd frontend/baro-app
npm ci
npx expo export --platform web      # 정적 웹 빌드(dist/)
```

### 관리자 웹 (Vue/Vite)
```bash
cd frontend/baro-web/admin-web
npm ci
npm run build                        # 산출물: dist/  (base: /admin/)
```

## 6. 배포 방법 (EC2 · Docker Compose)
1. EC2 접속 후 소스 최신화(또는 Jenkins CD 자동).
2. 백엔드/DB 컨테이너 기동:
   ```bash
   cd backend
   docker compose -f compose.prod.yaml up -d --build
   ```
   - 앱은 `127.0.0.1:8080` 및 Tailscale IP(`100.85.234.102:8080`)에 바인딩(엣지 접근용).
3. 프론트 정적 산출물 배포:
   - 입주민 앱 `dist/` → `/var/www/baro-app`
   - 관리자 웹 `dist/` → `/var/www/admin`
4. **Nginx** 리버스 프록시(요지):
   - `/api/` → `127.0.0.1:8080` (백엔드)
   - `/` → `/var/www/baro-app` (입주민 웹)
   - `/admin/` → `/var/www/admin` (관리자 웹, SPA fallback)
   - `/hw/` → `127.0.0.1:8080` (엣지 인바운드; 또는 Tailscale IP 바인딩으로 대체)
5. **HTTPS**: 도메인 `https://i15e202.p.ssafy.io` (SSAFY 제공 인증서/프록시).

<br>

### CI/CD (Jenkins)
- GitLab **Push Webhook** → Jenkins Job(Generic Webhook Trigger) → 빌드/배포.
- 백엔드/프론트 각각 `Jenkinsfile.cd`로 파이프라인 구성(`develop` 브랜치 트리거).
- Jenkins Credentials: DB 비번, `INTERNAL_API_KEY` 등 secret은 Jenkins Credentials로 주입.

<br>

## 7. 배포 시 특이사항
- **엣지↔서버는 공인 IP 없이 Tailscale 사설망**으로 연결(REST). 서버→Jetson 명령은 **아웃박스 패턴**(적재→재시도)으로 유실 없이 전송.
- 컨테이너 기동 시 Tailscale 인터페이스가 올라와 있어야 `100.85.234.102:8080` 바인딩 성공.
- 시간대는 전 구간 **Asia/Seoul** 고정(JVM/JPA/Jackson).
- 이미지 저장은 **EC2 로컬 디스크**(별도 오브젝트 스토리지 미사용).

## 10. DB 덤프 생성·배치
EC2에서 최신 스키마+데이터를 덤프하여 `exec/db_dump.sql`로 배치:
```bash
docker exec parking-backend-prod-mysql-1 sh -lc \
  'MYSQL_PWD="$MYSQL_PASSWORD" mysqldump -u"$MYSQL_USER" --databases "$MYSQL_DATABASE" \
   --single-transaction --routines --triggers' > db_dump.sql
```

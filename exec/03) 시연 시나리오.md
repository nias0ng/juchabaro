# 시연 시나리오 — 주차바로 (S15P11E202)

OBS로 화면을 전환하며 진행하는 실제 시연 순서입니다. (천장 카메라 → 관리자 웹 → 입주민 앱 순으로 장면 전환)

## 0. 사전 준비
- 백엔드/DB 컨테이너 기동, Nginx·도메인(`https://i15e202.p.ssafy.io`) 정상.
- 엣지(Jetson·Raspberry Pi) 전원 ON + Tailscale 연결(온라인).
- **OBS 씬 구성**
  - 씬 A: **주차장 천장 카메라**(Jetson 감시 화면)
  - 씬 B: **관리자 웹 대시보드**(`/admin`)
  - 씬 C: **입주민 앱 2분할** — 왼쪽 신고자, 오른쪽 차주
- **데모 계정**: 차주 `resident1 / 1234` (노란 차량 `12가3434` 소유), 신고자 `resident2 / 1234`, 관리자 `admin / 1234`.
- 시나리오 차량: DB에 등록된 **노란색 차량(일반 차량)** `12가3434`.

---

## 1. [OBS 씬 A · 천장 카메라] 입차 → 장애인구역 위반 → 현장 경고
1. 노란 차량이 입구 진입 → **Raspberry Pi 번호판 OCR로 입차 감지**(등록 차량 매칭, 입차 판정).
2. 차량이 **장애인 주차구역(DISABLED)** 에 주차.
3. 등록 정보상 **일반 차량**이므로 전용구역 위반 → **현장 경고 발생**: **LED 점등 + 경고 음성**("출차해 주세요" 안내)이 나온다.
4. 동시에 백엔드로 위반 사건 전이(OPEN) → 자동 이동 요청 생성.

## 2. [OBS 씬 B · 관리자 웹] 위반 대시보드
1. 관리자 웹(`admin / 1234`) 화면으로 전환.
2. 방금 발생한 **위반 상황이 대시보드/사건 목록에 실시간 표출**.
3. 사건 상세에서 위반 유형(장애인구역 위반)·차량·구역·상태 확인.

## 3. [OBS 씬 A→C · 천장 카메라 + 앱 2분할] 불편주차 목격 → 수동 신고 → 알림 교환
1. 화면 다시 **천장 카메라**로 전환 → 동일 노란 차량이 **불편 주차(주차선 침범 등)** 된 상황.
2. 사용자(신고자 `resident2`)가 이를 목격 → **앱에서 직접 사진 촬영**하여 해당 차량 **수동 이동(출차) 요청**.
3. OBS를 **앱 2분할**로 전환:
   - **왼쪽(신고자 resident2)**: 이동 요청 전송.
   - **오른쪽(차주 resident1)**: **푸시 알림 수신** → "차량 이동 요청" 확인 → 응답("이동하겠습니다").
   - 신고자에게 **응답 도착 알림** 수신 → 양쪽으로 알림이 오가는 장면 시연.

## 4. [OBS 씬 A · 천장 카메라] 출차 완료
1. 차주가 노란 차량을 이동 → **주차 구역에서 빠져나가 출차 완료**.
2. 세션 종료 → 주차 현황 정상화. 시연 종료.

---

### 시연 흐름 한 줄 요약
입차(OCR) → 장애인구역 위반 자동 감지 + **현장 LED·경고음성** → 관리자 대시보드 표출 → 불편주차 **수동 사진 신고** → 앱 신고자↔차주 **알림 교환** → **출차 완료**.

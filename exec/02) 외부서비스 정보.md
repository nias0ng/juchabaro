# 외부 서비스 정보 — 주차바로 (S15P11E202)


## 1. Expo Push (푸시 알림)
- **용도**: 입주민 앱 푸시 알림(이동 요청/재알림/전기차 초과/응답 도착 등).
- **가입/발급**: [expo.dev](https://expo.dev) 계정. 앱 실행 시 발급되는 **Expo Push Token**을 서버 `device_tokens`에 등록.
- **서버 연동**: `provider: expo`, 발송 엔드포인트 `https://exp.host/--/api/v2/push/send` (Expo Push API).
- **참고**: Android/iOS 실제 전송은 Expo가 내부적으로 FCM/APNs로 중계. 별도 FCM 키 불필요(Expo 관리형 기준).
- **필요 정보**: `〈Expo 계정〉`, (필요 시) Expo Access Token `〈token〉`.

## 2. GitLab (소스 · CI 트리거)
- **용도**: 형상 관리 + Jenkins CI/CD 웹훅 트리거.
- **연동**: 프로젝트 → Settings → Webhooks → **Push events** → Jenkins Generic Webhook URL(토큰 포함).
- **필요 정보**: 저장소 URL `lab.ssafy.com/s15-webmobile3-sub1/S15P11E202`, 배포용 read Deploy Token 계정 `gitlab+deploy-token-6546` (Jenkins Credential `gitlab-s15p11e202-read`). 토큰 secret은 Jenkins Credentials에 보관.

<br>

## 3. Tailscale (엣지 ↔ 서버 사설망)
- **용도**: 공인 IP 없이 EC2 ↔ Jetson/Raspberry Pi 간 안전한 REST 통신(WireGuard 기반).
- **가입/발급**: [tailscale.com](https://tailscale.com) 계정(SSO). 각 노드 `tailscale up`으로 tailnet 조인(또는 **Auth Key** 사용).
- **필요 정보**: tailnet 계정, (자동 조인 시) Auth Key `〈key〉`, 노드 IP(EC2 `100.85.234.102`, Jetson `100.99.37.7`).
- **ACL**: EC2 ↔ 엣지 필요한 포트(8080/8000) 허용.
